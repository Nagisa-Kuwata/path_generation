# Quickstart: ロボットリアルタイム経路生成・迷路走破シミュレータ

**Branch**: `001-robot-maze-simulator` | **Date**: 2026-03-24

---

## 前提条件

- Rust stable toolchain（`rustup` でインストール済み）
- `cargo` が PATH に通っている
- Windows / Linux / macOS のいずれか

```bash
rustup update stable
```

---

## ビルドと起動

```bash
# リポジトリをクローン
git clone https://github.com/Nagisa-Kuwata/path_generation.git
cd path_generation

# デバッグビルドで起動（開発中）
cargo run

# リリースビルドで起動（パフォーマンス検証時）
cargo run --release
```

---

## シードを指定して起動（再現可能な迷路）

```bash
# 環境変数でシードを渡す（実装時に --seed オプションまたは環境変数を選択）
cargo run --release -- --seed 12345
```

- シードが省略された場合はランダムシードが使用される。
- 同一シードは常に同一の迷路・目標位置を生成する。

---

## UI の操作方法

| 操作 | 説明 |
|------|------|
| 「開始」ボタン | ロボットの探索を開始する。探索中はグレーアウトされ押下不可 |
| 「再起動」ボタン | 実行中・完了後いずれでも押下可。迷路を再生成し「開始」前に戻る |

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| ウィンドウが起動しない | `cargo run --release` で再試行。GPU ドライバを更新する |
| ロボットが動かない | 「開始」ボタンが押されているか確認。グレーアウト中は探索中 |
| 迷路が常に同じ | `--seed` オプションが固定値になっていないか確認 |
| ビルドエラー | `rustup update stable` で toolchain を最新化する |
